## Regla para la revisión

Cuando solo cambia la metáfora o el nombre, la propuesta distingue **el lenguaje** sin afirmar que haya una práctica distinta. Si Lucía no puede confirmar un criterio de elección claro, conviene revisar el posicionamiento de esos registros antes de aprobar sus textos. Las fichas individuales documentan el problema y la pregunta correspondiente.
