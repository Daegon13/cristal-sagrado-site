# Comparación visual de Home

Capturas completas de Chrome headless realizadas el 6 de octubre de 2026. **Before** corresponde al commit `0421a15` (antes del rediseño sin commit); **proposed** corresponde a la propuesta actual. Se forzó recarga sin caché en cada captura. Chrome headless no sustituye Safari iOS, Chrome Android ni Instagram en teléfono real.

La versión anterior tenía violeta, dorado, fondo estrellado y superficies cristalinas, pero ocho intenciones, un hamburger móvil y una Home con otro orden. La propuesta conserva la estructura de conversión actual y recupera selectivamente esas señales de marca. El único asset nuevo es un fotograma WebP del video ya aprobado; no se incorporaron imágenes de terceros.
