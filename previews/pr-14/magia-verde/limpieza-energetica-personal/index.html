¿Qué tipo de consulta es?

La limpieza se presenta como una práctica espiritual. Si hay síntomas físicos o emocionales persistentes, corresponde consultar también con un profesional de salud.

La ficha relaciona esta práctica con mudanzas, rupturas, ambientes percibidos como tensos y momentos de transición. En la página se usa ese lenguaje como descripción de una experiencia subjetiva. No se atribuye una causa médica al cansancio ni se promete aliviar síntomas. Si hay malestar persistente, buscá atención profesional además de cualquier consulta espiritual.

Puede tener sentido si...

Se consulta tras cambios de etapa, ambientes que se sienten densos o momentos de cansancio subjetivo.
